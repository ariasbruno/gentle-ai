# Antigravity CLI Integration — Phase 6: Asset Ownership & Drift Policy

Where every asset in the gentle-ai ↔ antigravity-cli integration comes from, who owns it, and
how content drift between runtimes is now detected instead of discovered by accident.

**Outcome of the 2026-09-22 audit**: all three drift findings were resolved at root — skill
mirroring with provenance, a CI drift test, sync transparency, and one deliberate semantic fix.
No preset policy or generated alias was changed.

---

## 1. Quick path

1. Run `go run ./scripts/transpile-antigravitycli --strict` — regenerates transpiled assets,
   mirrored skill aux files, and `.skills-mirror.json` deterministically.
2. Run `go test ./internal/assets/...` — the drift test
   (`TestMirroredSkillsMatchManifest`) fails on any silent divergence or undeclared stray.
3. Run `gentle-ai sync --dry-run` — the output names every skill excluded by preset policy.

## 2. Ownership map

| Asset class | Source of truth | Installed to agy via | Drift protection |
|---|---|---|---|
| Plugin manifest (`plugin.json`) | `internal/assets/antigravitycli/plugin.json` | SDD bundle sync + first native import | schema test + post-write check |
| Subagents (24), chains, orchestrator docs | gentle-shell `assets/` | transpiler → `internal/assets/antigravitycli/` | deterministic regeneration + invariant tests |
| Skill **aux files** (`references/*`) for the 11 overlapping skills | gentle-shell `skills/` | transpiler → `internal/assets/skills/<name>/` | provenance comment + sha256 in `.skills-mirror.json` + drift test |
| Skill **SKILL.md** forks (same 11) | gentle-ai (deliberate specialization) | sync component | declared `ownedFiles`; never overwritten |
| `_shared` contracts | gentle-ai (superset with SDD contracts) | sync component | excluded from mirroring by design |
| SDD skills (`sdd-*`), `go-testing`, `gentle-ai-bench`, `hermes-*` | gentle-ai only | sync component | n/a — no upstream counterpart |
| Contributor skills (`branch-pr`, `comment-writer`, `issue-creation`, `rdd-defect-workflow`, `systemic-issue-triage`, `gentle-ai-bench`) | gentle-ai only | **not installed by any preset** (policy, not bug) | sync output now names them + `--skills` hint |

After every component, routing refresh, and compatibility-skill refresh has finished, sync checks
`~/.gemini/config/import_manifest.json`. If `gentle-ai` is absent, it copies the completed plugin
tree to a distinct temporary source and runs `agy plugin install <staging>`. An existing import is
never reinstalled, so `importedAt` remains byte-stable. `agy plugin list` and the import manifest are
the activation proof; `agy mcp list` only describes global MCP configuration.

**AGY 1.2.9 warning**: `agy plugin list` rewrites `import_manifest.json` and is not read-only when
unrelated root fields or imports exist. Run the activation proof against a disposable copy of the
isolated HOME; do not patch the global AGY installation.

**Why SKILL.md is fork-owned**: the gentle-ai copies are a deliberate specialization —
frontmatter `name:` without the `gentle-ai-` prefix, richer contracts (issue-creation v1.4,
judgment-day receipt clause), and multiple tests enforce them. Verbatim upstream mirroring of
SKILL.md fails 8 pre-existing contract tests.

**The `sdd-propose` alias is intentional**: generated by the transpiler so both the phase
spelling (`sdd-propose`) and the packaged subagent name (`sdd-proposal`) resolve. Pinned by the
exactly-24-subagents invariant test. See `scripts/transpile-antigravitycli/README.md` →
"Generated aliases".

## 3. Drift policy

1. **Single regeneration command**: all transpiled + mirrored content comes from
   `go run ./scripts/transpile-antigravitycli --strict`. Zero manual edits under
   `internal/assets/antigravitycli/`; SKILL.md forks change deliberately in-repo.
2. **CI drift detection**: `.skills-mirror.json` records sha256 for every mirrored and owned
   file; `internal/assets/mirrored_skills_test.go` fails on hash mismatch, missing provenance,
   or undeclared strays — without needing a gentle-shell checkout.
3. **Sync transparency**: `RenderSyncReport` prints `Excluded by preset policy: … — pass
   --skills to include` whenever a preset-based selection silently drops contributor skills.
4. **Version fields are not trust anchors**: both judgment-day copies claimed
   `metadata.version: "1.7"` while contradicting each other. Ownership declarations, not
   version strings, are the contract.
